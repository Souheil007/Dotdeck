## 1. Global Anti-Slop Enforcement (Leonxlnx Taste Skill `tells.md`)

The following patterns are **STRICTLY BANNED** across all Dotdeck surfaces:
- ❌ **No violet/indigo gradients or glowing blobs** on heroes, buttons, or backgrounds.
- ❌ **No gradient-filled headline text** (Use crisp solid high-contrast ink).
- ❌ **No cookie-cutter 3-card feature rows** with centered icons in rounded squares.
- ❌ **No tracked uppercase eyebrows / kickers** (`EYEBROW` or `FEATURE`) above every heading.
- ❌ **No pill badges with generic marketing text** ("New", "Beta", "Introducing").
- ❌ **No generic AI marketing copy** ("Unlock", "Supercharge", "Seamless", "Elevate", "Effortless", "All-in-one").
- ❌ **No soft grey drop shadows under every card** (`rgba(0,0,0,0.1)`). Use architectural hairlines and discrete tone steps.
- ❌ **No scattered non-user-triggered animations**. Motion is strictly reactive (user clicks, wire snaps, packet pulses).

## 3. Typographic System (Developer Mono + Technical Grotesk)

- **Display & Headings**: `Plus Jakarta Sans` (Tight negative tracking `-0.025em`, font-weight `600` or `700`).
- **Body & Controls**: `IBM Plex Sans` (Ultra-legible, neutral, sentence-case, line length `<72` chars).
- **Telemetry & Monospace**: `JetBrains Mono` (`font-mono tabular-nums`, tokens, timestamps, step chevrons `>`).

## 5. Interaction Motion Tokens (Jakubantalik Transitions.dev)

- **Tactical Spring Snap (`--ease-spring`)**: `cubic-bezier(0.34, 1.56, 0.64, 1.0)` (250ms)  
  *Usage: Wire port locks, switch toggle flips, pin snapping.*
- **Tactical Deceleration (`--ease-out`)**: `cubic-bezier(0.16, 1.0, 0.3, 1.0)` (350ms)  
  *Usage: Slide-out telemetry drawer, modal pop-ins, pan-to-node.*
- **Electrical Pulse Wire**: CSS linear dashed keyframe with synchronized glowing wave head.
- **Accessibility Fallback**:
```css
@media (prefers-reduced-motion: reduce) {
  *, ::before, ::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

## 6. Pre-Delivery Audit Checklist (UI UX Pro Max Quality Floor)

- [ ] Zero single-word gradient/italicized headline accents.
- [ ] No generic SaaS card kit with 80px whitespace.
- [ ] Tabular numbers (`tabular-nums`) used for all timestamps, step metrics, and telemetry counters.
- [ ] Light mode contrast $\ge 4.5:1$ (WCAG AA), AAA ($7:1$) on primary commands.
- [ ] Visible focus rings on keyboard navigation (`:focus-visible`).
- [ ] Tested at `375px`, `768px`, `1024px`, and `1440px`.
